  <p class="fea-eb">Masterclass gratuita + oferta da Black Friday Vitalícia</p>

<script>
(function(){
  /* Fim da contagem: segunda, 9/11/2026, 20h de Brasília (UTC-3, sem horário de verão) */
  var alvo = new Date('2026-11-09T20:00:00-03:00').getTime();
  var el = document.getElementById('fea-mtb-cd');
  if(!el) return;
  function dois(n){return (n<10?'0':'')+n;}
  function tick(){
    var s = Math.floor((alvo - Date.now())/1000);
    if(s <= 0){ el.textContent = 'a aula começou, ao vivo no Zoom'; return; }
    var d = Math.floor(s/86400), h = Math.floor(s%86400/3600), m = Math.floor(s%3600/60);
    el.textContent = 'faltam ' + (d>0 ? d+'d ' : '') + dois(h)+'h ' + dois(m)+'min';
    setTimeout(tick, 1000*(60 - new Date().getSeconds()) || 1000);
  }
  tick();
})();
</script>

Contagem: termina sozinha em 9/11 às 20h de Brasília e passa a mostrar "a aula começou, ao vivo no Zoom". Se o WP Rocket atrasar o script até o primeiro toque, a linha mostra "ao vivo no Zoom" nesse meio tempo, sem quebrar nada.
