# Kit de imagens no ChatGPT (etapa 3)

Imagem vence texto no Seedance: tudo que precisa sair exato vira imagem antes. Gerar no ChatGPT
(não gasta crédito do Higgsfield). Conferir cada imagem antes de seguir: texto letra a letra,
marca visível, física do objeto, coerência com os outros objetos.

Regra FEA: IA gera imagem de cenário, figurino e objeto para o vídeo de IA aprovado pela Keila;
nunca imagem clínica ou de paciente.

## Cenário vazio a partir de foto real
```
Use the attached photo as the exact reference for this real [room]: [materiais e móveis vistos na foto]. Keep the same materials, colours and layout. Recreate it as an EMPTY scene with no people.
Recompose it as a vertical 9:16 frame, eye level, [de onde a câmera olha]. On the [mesa]: [o que fica].
Remove completely: [logos, marcas, papéis, objetos pessoais, qualquer texto], and any person.
It is night [...]: [fontes de luz], a faint rosé glow (#E48AA0) [...], deep shadows (#0F0507) in the corners. Cinematic spy-film suspense, quiet, photorealistic, 35mm lens, shallow depth of field.
```
Logo do cliente na parede pode ficar se a Keila quiser; no prompt de vídeo, câmera quase parada e
logo desfocado ao fundo, com "the emblem stays fixed and unchanged".

## Figurino "fantasma" (três vistas, sem rosto)
Anexar 3 fotos de corpo inteiro da pessoa (só proporção do corpo).
```
Using the attached photos only for the man's body proportions and build (ignore his clothes, his face and the backgrounds), create a clothing reference sheet: the same outfit shown in three views side by side, front, three-quarter and back, on an invisible body, like a ghost wearing the clothes, with no head, no face, no hands and no skin visible. Outfit: [peça por peça]. [Acessórios permanentes do card: relógio, aliança] placed beside the figures. Plain light grey studio background, soft even light, photorealistic, no text, no logos.
```
Mulheres sem gravata/camisa aberta = folha própria. Óculos escuros entram na folha quando a cena pede.

## Objeto com texto curto
```
[Objeto], seen straight from above, on a plain dark grey surface. [Detalhe] with the single word "[PALAVRA]" typed in [estilo], spelled exactly [P-A-L-A-V-R-A]. Vertical 9:16 frame, soft moody light, photorealistic, no other text, no logos.
```
Soletrar a palavra no prompt. Até ~3 palavras; texto maior vai para a edição (o cartão da missão
foi gerado em branco).

## Objeto em outro estado (aberto, com algo dentro)
Sempre na mesma conversa ou anexando a imagem oficial do objeto:
```
Combine the two attached images. Take the [objeto 1] from the first image, keep it exactly the same [...], but [mudança de estado], and put inside it, halfway out, the exact [objeto 2] from the second image: the same shape, proportions, [traços], unchanged. Same background and light, seen from above, vertical 9:16, no other text or logos.
```
Objeto que guarda outro precisa de volume: "make it thicker and slightly bulging, as if a small
[objeto] is inside it".

## Ajuste pontual numa imagem aprovada
```
Keep this image exactly the same, every detail, framing and light. Only [a única mudança].
```
