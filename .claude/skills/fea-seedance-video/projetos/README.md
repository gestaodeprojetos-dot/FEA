# Projetos

Um arquivo por projeto de vídeo: `projetos/<projeto>.md`. Crie no primeiro pedido do projeto e
atualize a cada cena. Modelo:

```
# <Projeto>

- Formato: 9:16 (vertical) ou 16:9
- Plataforma: Higgsfield, Seedance 2.5 (Draft para testar, 1080p para finalizar)
- Pasta dos vídeos: <caminho no computador>

## Elenco
- <Nome>: card em personagens/<nome>/card.md; figurino deste projeto; como atua (ex.: gesticula
  pouco, sorri sem mostrar os dentes).

## Convenções de câmera
- Ex.: câmera parada nos diálogos; close de um personagem sempre do mesmo lado.

## Anexos padrão
- @Image1 cenário vazio, @Image2… fotos do rosto, roupa por último.

## Onde a cena parou
- Última cena aprovada, estado de cada personagem (posição, o que segura, para onde olha).

## Histórico
- O que deu errado e o que resolveu, uma linha por cena.
```
